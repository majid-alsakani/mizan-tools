# Image Compressor validation

تم التحقق من الأداة داخل متصفح باستخدام صورة PNG تجريبية مقاسها `1600 × 900` وحجمها `1.59 MB`.

| التحقق | النتيجة |
| --- | --- |
| تنفيذ الضغط داخل المتصفح | نجح دون استدعاء شبكة أو رفع ملف |
| صيغة المخرج الافتراضية | WebP |
| حجم المخرج في الحالة التجريبية | `10.4 KB` |
| عرض المعاينة الأصلية والنتيجة | ناجح |
| إنشاء رابط تنزيل باسم آمن | `mizan-test-mizan.webp` |
| اختبارات وحدات المحرك | 7 ناجحة |

التوفير الظاهر في هذه الحالة التجريبية ليس معيارًا مضمونًا للصور الحقيقية؛ فهو يتغير بحسب المحتوى والصيغة وإعدادات الجودة.
